## Summary

Splits props into multiple groups based on key sources. Each source gets its own result object containing all its matching keys. The first component source claims styling props (class/className/style). Subsequent components only receive variant props. Arrays receive their listed keys but don't claim styling props. The last element is always the "rest" containing keys not claimed by any source.
