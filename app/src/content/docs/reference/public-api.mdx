Clava’s public surface is intentionally small. Use this page to understand the shape of the package, then jump into [API Symbols](/reference/api/) for exact signatures and source links.

## Core builders

- `create()` produces customized `cv` and `cx` helpers.
- `cv()` defines a variant-driven component API.
- `cx()` merges class values into the final class string.
- `splitProps()` separates styling-aware inputs from the rest of a prop object.

## Output contracts

- The default component result exposes `class` and normalized `style`.
- Mode-specific helpers provide `jsx`, `html`, and `htmlObj` outputs.
- The generated reference covers the corresponding helper types and interfaces in detail.
