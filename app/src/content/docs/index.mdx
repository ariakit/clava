## Why Clava

Clava is aimed at teams that want the ergonomics of variant-based styling without locking their design system to one rendering model. The v0 docs set is intentionally small, but the site structure is already the final one: Start, Guides, Reference, and a changelog that grows with the package.

## One component, three output modes

<Tabs syncKey="clava-output">
  <TabItem label="JSX">

```ts
import { cv } from "clava";

const button = cv({
  class: "inline-flex items-center rounded-md font-medium",
  variants: {
    size: {
      sm: "h-8 px-3 text-sm",
      md: "h-10 px-4 text-sm",
    },
    tone: {
      solid: "bg-black text-white",
      subtle: "bg-zinc-100 text-zinc-900",
    },
  },
  defaultVariants: {
    size: "md",
    tone: "solid",
  },
});

button.jsx({ size: "sm" });
```

  </TabItem>
  <TabItem label="HTML string">

```ts
button.html({ tone: "subtle" });
```

  </TabItem>
  <TabItem label="HTML object">

```ts
button.htmlObj({ size: "sm" });
```

  </TabItem>
</Tabs>
