Clava ships as a normal package and does not require framework-specific setup to start defining variant-driven style APIs.

## Add the package

<Tabs syncKey="package-manager">
  <TabItem label="pnpm">

```bash
pnpm add clava
```

  </TabItem>
  <TabItem label="npm">

```bash
npm install clava
```

  </TabItem>
  <TabItem label="Yarn">

```bash
yarn add clava
```

  </TabItem>
</Tabs>
