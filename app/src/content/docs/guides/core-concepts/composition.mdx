---
title: Composition
description: Extend and compose Clava components without losing the API shape.
---

Composition is where Clava becomes a system tool instead of a single-component helper. Extend base components when the styling contract should carry forward, and keep the extension points obvious in your exported API.

## Planned focus

- `extend` for shared component families.
- Organizing base components that should remain internal.
- Keeping composition predictable when multiple layers define defaults or computed behavior.
