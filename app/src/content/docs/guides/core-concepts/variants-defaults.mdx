Variants define the knobs of your component API. Default variants define the baseline state consumers receive when they do not pass an explicit value.

## What belongs here

- Stable component decisions like size, tone, density, or layout.
- Defaults that represent the most common state rather than the most dramatic one.
- Variant names and values that read like API surface, not implementation trivia.
