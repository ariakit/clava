This recipe track is reserved for system-scale patterns: shared primitives, constrained extension points, and public APIs that multiple teams can consume without reading the implementation.

## Planned recipes

- Layering base, primitive, and product-level components.
- Setting defaults that stay stable across a system.
- Exposing only the variant surface that downstream teams should depend on.
