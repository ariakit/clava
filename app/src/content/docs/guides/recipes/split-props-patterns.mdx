title: splitProps Patterns
description: Route variant-aware props to the right layer without leaking styling concerns.

`splitProps` is the recipe bridge between a styled component API and the rest of an element or wrapper contract.

## Planned recipes

- Splitting props between style primitives and host elements.
- Passing variant props through composed components without duplicating key lists.
- Keeping `class` and `style` ownership predictable when multiple components participate.
