Clava overlaps with CVA conceptually, but it expands the model around output modes, composition, and variant-aware prop handling.

## Migration shape

- Start by mapping existing variant objects and defaults to `cv()`.
- Decide whether your current component boundaries need `splitProps`.
- Keep the initial migration shallow, then adopt multi-mode outputs or `create()` only where they provide a real benefit.
